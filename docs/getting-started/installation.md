# Installation

## Requirements

- Python 3.12 or higher

## Install from PyPI

```bash
pip install CanvasGroupy
```

## Install from source

```bash
git clone https://github.com/FleischerResearchLab/CanvasGroupy.git
cd CanvasGroupy
pip install -e .
```

## Dependencies

CanvasGroupy depends on:

- [canvasapi](https://github.com/ucfopen/canvasapi) — Python wrapper for Canvas LMS REST API
- [PyGithub](https://github.com/PyGithub/PyGithub) — Python wrapper for GitHub REST API
- [pandas](https://pandas.pydata.org/) — Data manipulation
- [numpy](https://numpy.org/) — Numerical computing
